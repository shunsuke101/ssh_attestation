# 2026-08-31 の収集

対象カテゴリ: impl

## impl

- **[high]** ssh-attest-proxy — smallstep — https://github.com/smallstep/ssh-attest-proxy
  - FIDO `-sk` 鍵の attestation を SSH 証明書の独自 extension `ssh-sk-attest-v01@step.sm` に埋め込み、サーバ側の `AuthorizedPrincipalsCommand` で検証する PoC。「Evidence を SSH のどのレイヤに載せるか」への実装済みの一解。
- **[medium]** go-attestation v0.6.3 / v0.6.4 — google — https://github.com/google/go-attestation/releases
  - EK ベースの鍵 attestation プロトコル（credential activation）を実装、v0.6.4 で Windows TPM 2.0 にも対応。TPM 上の鍵が「本当にその TPM 内で生成された」ことを示す部品。
- **[medium]** Keylime v7.14.0 / v7.14.3 — keylime — https://github.com/keylime/keylime/releases
  - v7.14.0 で agent 主導の push attestation と API v2.5 の `/verify/evidence` エンドポイント、AMD SEV-SNP 検証を追加。Verifier を独立サービスに置く設計の参考。
- **[medium]** trust-key — justindal — https://github.com/justindal/trust-key
  - Raspberry Pi 上の試作。FIDO2 によるユーザ認証と TPM 2.0 の PCR 0 quote によるマシン識別を 1 つの attestation payload に束ねる。SSH 証明書発行は未実装。
- **[medium]** ssh-pubkey-server — flashbots — https://github.com/flashbots/ssh-pubkey-server
  - SSH ホスト公開鍵を `/pubkey` で HTTP 配信し、attested proxy 経由で取得して `known_hosts` に入れる想定の小さなサーバ。README に attestation 技術の記述はなく、束縛方法は不明。
- **[medium]** ssh-sk-verify — supply-chain-tools — https://github.com/supply-chain-tools/ssh-sk-verify
  - ssh-sk（FIDO）鍵の attestation を検証する Go ツール。Apache-2.0、2026-04-22 更新。
- **[medium]** online-attestation-ca — joostd — https://github.com/joostd/online-attestation-ca
  - attestation を検証してから SSH 証明書を出すオンライン CA のデモ。Verifier を CA に兼務させる型。
- **[low]** tpm2-tools 5.8 — tpm2-software — https://github.com/tpm2-software/tpm2-tools/releases
  - 2026-07-15 リリース。複数の脆弱性修正とメモリリーク・バッファオーバーフロー修正が中心で、attestation 機能の新規追加はない。
- **[low]** Parsec 1.5.0 — parallaxsecond — https://github.com/parallaxsecond/parsec/releases
  - 2026-05-01 リリース。ロゴ更新・依存バージョン更新が中心で、attestation に関わる変更はない。
- **[low]** ssh-sk-example — JackOfMostTrades — https://github.com/JackOfMostTrades/ssh-sk-example
  - SSH SK attestation document を検証する最小例（2021）。
- **[low]** ssh-sk-attestation-poc — joostd — https://github.com/joostd/ssh-sk-attestation-poc
  - SSH セキュリティキー attestation の PoC（2024-02）。
- **[low]** posh-ssh-sk-attestation-tool — WillSmartYubico — https://github.com/WillSmartYubico/posh-ssh-sk-attestation-tool
  - OpenSSH の attestation ファイルを検証して公開鍵を取り出す PowerShell ツール（2022）。
- **[low]** tpm-ssh-agent — ssh-slb9673-playground — https://github.com/ssh-slb9673-playground/tpm-ssh-agent
  - I2C 接続の TPM（SLB9673）向け TCTI を含む ssh-agent 実験実装。
- **[low]** yk-init — phiekl — https://github.com/phiekl/yk-init
  - YubiKey を OpenPGP モードで Ed25519 鍵に初期化するスクリプト。SSH 利用と attestation を想定。

### 新着なしだったもの

- OpenSSH リリースノート — 最新は 10.5（2026-08-11）で `openssh:10.5` として既読。10.4 / 10.3 も attestation 関連の変更はなく、対象外。
- ssh-tpm-agent — 最新は v0.9.0（2026-05-04）で既読。
- OpenSSH PROTOCOL 系ファイル — 既読分から変化なし。
- sigstore — 最新 v1.10.9（2026-08-03）は TUF client の deprecate と Azure KMS 対応で、attestation とは無関係のため除外。
